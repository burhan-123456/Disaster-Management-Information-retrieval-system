# 🌍 Disaster Information Retrieval System

An **NLP and Information Retrieval (IR) based web application** that takes a disaster-related query (e.g., *"flood"*) and returns the **top 3 most relevant results** using **TF-IDF and cosine similarity**.

---

## 🚀 Features

* Search disaster-related queries
* Top 3 relevant results
* Uses NLP + IR techniques (TF-IDF)
* Simple Flask web interface

---

## 🛠️ Tech Stack

Python, Flask, Scikit-learn, Pandas, HTML, CSS, JavaScript
